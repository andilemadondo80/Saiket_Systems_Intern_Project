# Saiket_Systems_Intern_Project
This is a Web Development project divided into 6 tasks, it showcases the coding fundamentals like HTML, CSS, JavaScript.
Saiket Systems – Web Development Internship Tasks

A collection of six front-end web development projects completed as part of my Web Development Internship task with Saiket Systems. The projects demonstrate practical skills in HTML5, CSS3, and JavaScript, with an emphasis on functionality, responsive design, and user experience.

Project Overview

The project consists of six tasks, each focusing on a different aspect of front-end web development. The interface features a premium dark visual theme combining navy blue and black gradients, subtle blue accents, glass-style components, and interactive hover effects.

Tasks Completed

Task 1: Personal Portfolio

A responsive personal portfolio website designed to present professional information, skills, projects, and contact details.

Features:

Structured portfolio sections.

Responsive page layout.

Contact form validation.

Task 2: E-Commerce Product Page

An interactive product page demonstrating essential online shopping functionality.

Features:

Product images and information.

Quantity selection.

Add-to-cart functionality.

Cart subtotal calculation.

Task 3: Navigation Menu

A styled navigation interface designed to improve website navigation and usability.

Focus areas:

Navigation structure.

Interactive menu behaviour.

Responsive presentation.

Task 4: HTML Forms

A form-based interface demonstrating user input collection and client-side validation.

Features:

Text input fields.

Radio buttons and checkboxes.

Dropdown selection.

Form validation.

Task 5: Blogging Platform

A browser-based blogging application demonstrating content management and dynamic page updates.

Features:

Create, edit, and manage blog posts.

Organise posts using categories.

Store content using browser local storage.

Safely render user-generated content.

Task 6: Interactive Productivity App

An interactive application combining a focus timer with a task-tracking system.

Features:

Focus timer functionality.

Task creation and tracking.

Dynamic interface updates.

Persistent task data using browser local storage.

Technologies Used

HTML5 – Semantic structure and content.

CSS3 – Responsive layouts, gradients, animations, and visual styling.

JavaScript (ES6+) – Application logic, DOM manipulation, form validation, and interactive functionality.

Local Storage API – Browser-based persistence for supported features.
